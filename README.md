# Department Service

This project manages department details and is connected with the employee-service application

## Features
- Add departments
- View department details
- Update department details
- Delete departments
- Provide department information to employee-service

## Database
department_service_db

## Run the project
1. Import the project into Eclipse.
2. Configure MySQL in - application.properties.
3. Run the Spring Boot application.
